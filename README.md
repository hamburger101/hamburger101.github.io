# Reagent Launcher

Mods for your Steam, Epic Games and Xbox games as Off/On switches.

- Website: https://hamburger101.github.io/
- Download: the newest release on the [Releases](https://github.com/hamburger101/ReagentLauncher/releases/latest) page

This repository holds the website, generated by `website/build_site.py` in the launcher's
project; edits made here are replaced by the next deploy.
